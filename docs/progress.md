# 進捗

## 現在地（2026-10-19）

毎日使える形になった。最初の割り当て（左 ⌘ で英数、右 ⌘ でかな、右 ⌥ でボポモフォ）、ログイン時の起動、二重起動の防止、割り当てを置き直す小さな画面まで、できている。アイコンは仮置き。ソースだけを MIT ライセンスで公開した（2026-10-19。要件の「主な利用者」）。

## 次にやること

## 確かめ方

実機で確かめる項目と、期待する動き。どれも期待どおりに動くことを確かめてある。

- 確かめた環境: Apple Silicon の Mac、内蔵の US 配列。割り当ての画面は macOS 26.5、それより前の項目は macOS 14.7 で確かめた（macOS 26.5 でも動く）
- ログは `log stream --predicate 'subsystem == "io.github.takashi-w.anykana"' --level debug` で見る。押したキーの枠（`leftCommand`・`rightOption` など）や、送ったキー（`posted key 102` など）が出る
- 止めるときは `pkill -x AnyKana`

### 準備

1. ⌘英かな などの、同じことをするアプリを終了する（両方動いていると、二重に切り替わる）
2. `open ~/Applications/AnyKana.app`
3. 権限の案内が2つ出たら、システム設定で入力監視とアクセシビリティの両方で AnyKana をオンにする。2 秒ほどで動き始める。動かなければ `pkill -x AnyKana` で止めて、もう一度 `open` する

### 左右の ⌘

| # | やること | 期待 |
| --- | --- | --- |
| 1 | テキストエディットで、左 ⌘ をタップ | 英数になる |
| 2 | 右 ⌘ をタップ | かなになる |
| 3 | ⌘C・⌘V・⌘Tab | 切り替わらない |
| 4 | Chrome で ⌘クリック | 新しいタブに開き、切り替わらない |
| 5 | Shift を押したまま ⌘ をタップ | 切り替わらない（⌘英かな とはここだけ違う） |
| 6 | CapsLock をオンにして、左 ⌘ をタップ | 英数になる |
| 7 | fn を押したまま ⌘ をタップ | 切り替わらない |
| 8 | Chrome・Slack・ターミナルでも 1 と 2 | 同じ |
| 9 | Figma か地図で、⌘ を押したままスクロールして離す | 切り替わらない |
| 10 | トラックパッドで勢いよくスクロールし、止まる前に左 ⌘ をタップ | 英数になる（指を離したあとの慣性のスクロールは数えない） |
| 11 | `scripts/build-app.sh` で作り直して `open` | 権限を付け直さずに動く |

### 左右の ⌥ と 🌐

| # | やること | 期待 |
| --- | --- | --- |
| 1 | 左 ⌥・🌐 をタップ（割り当てなし） | ログに `leftOption`・`globe` が出るだけで、何もしない |
| 2 | ⌥E のあと e（é を打つ） | ログに枠が出ない |
| 3 | 右 ⌘ を押したまま右 ⌥ を押して離す | 切り替わらない |
| 4 | Finder でメニューを開いたまま、⌥ を押して離す（隠れた項目をのぞく） | 単独で押して離したことになるので、割り当てがあれば切り替わる（⌥ でメニューをのぞく使い方とはぶつかる） |

| # | やること | 期待 |

### ログイン時の起動と、二重起動の防止

| # | やること | 期待 |
| --- | --- | --- |
| 1 | システム設定 → 一般 → ログイン項目 | 「ログイン時に開く」に AnyKana がある |
| 2 | ログアウトしてログインし直す（か再起動） | AnyKana が動いていて、割り当てたキーが効く。権限を付け直さなくてよい |
| 3 | AnyKana が動いているときに `open -n ~/Applications/AnyKana.app` | 2つ目はすぐに終わる（`pgrep -x AnyKana` が1つ） |
| 4 | ログイン項目で AnyKana をオフにして、`pkill -x AnyKana` → `open` | ログイン項目はオフのまま（登録し直さない）。オンに戻すのは、ログイン項目の ＋ で `~/Applications/AnyKana.app` を選ぶ |

### 割り当ての画面

| # | やること | 期待 |
| --- | --- | --- |
| 1 | AnyKana が動いているときに、Spotlight で AnyKana を開く（か `open ~/Applications/AnyKana.app`） | 小さな画面が前に出る。左 ⌘ は ABC、右 ⌘ は日本語、右 ⌥ は注音、左 ⌥ と 🌐 は「なし」（名前は macOS の表示のまま） |
| 2 | 画面を見る | 枠は左 ⌘・右 ⌘・左 ⌥・右 ⌥・🌐 の順に並び、キーは刻印のように枠で囲まれる。説明の文はない。文言と入力ソースの名前は、システムの言語で出る |
| 3 | ポップアップを開く | 入力メニューと同じ入力ソースが並ぶ |
| 4 | 右 ⌥ を「なし」、🌐 を注音にする | 枠の下に、リンク付きの一言（「🌐 キーを押して」を「何もしない」に）が出る |
| 5 | システム設定 → キーボードの「🌐 キーを押して」を「何もしない」にしてから、🌐 をタップして `su` | ㄋㄧ と出る。右 ⌥ では切り替わらない |
| 6 | 画面を開いたまま、左右の ⌘ をタップ | ふだんどおり英数・かなになる |
| 7 | ⌘W、esc | 画面が閉じる |
| 8 | `pkill -x AnyKana` → `open` | 4 の割り当てのまま（`defaults read io.github.takashi-w.anykana keyMap` にも出る）。動いていないときに開いたので、画面は出ない |
| 9 | もう一度開き、「Quit AnyKana」（日本語なら「AnyKana を終了」） | 終わる（`pgrep -x AnyKana` が空）。`open` で戻る |
